# Project evidence library

The repository owns code, tests, reusable contracts, generic research and concise
status. The private FitnessData library owns recordings, rider-specific plans and
reviews, detailed run receipts, original input identifiers and machine-specific
bench/operational inventories. Historical Git commits are retained unchanged; this
is a current-document ownership change, not confidentiality-driven history rewriting.

## Locate the retained evidence

Read the FitnessData root README for the library convention and machine-local root.
The completed archive is under this path relative to that root:

```text
projects/zwift-race-coach/project-history/2026-11-06-pre-public-consolidation/
```

- `snapshot/`: the 39 original Coach files at checkpoint `b6bdccc`.
- `coach-original.bundle`: complete, unchanged six-commit Coach history.
- `working-tree/`: combined-project evidence documents before relocation.
- `provenance.json` and `copy-receipt.json`: exact source checkpoints and file hashes.

The 59 selected artifacts were copied without overwriting and verified by Windows
PowerShell 7 and independently through mounted-byte SHA-256 reads on 2026-11-06.
The receipt is the 60th file. Cloud synchronization, cross-machine availability and
independent backup remain unverified. Original local Coach files remain intact.
No activity exports, live databases, credentials or untracked account state were
selected. Existing library session indexes and earlier receipts are unchanged.

Use the entries below to select a report, then verify its hash using the receipt.
Archived Markdown retains its original context and may reference the old repository
layout; it is evidence, not a stand-alone current documentation site or a launcher.
